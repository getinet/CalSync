# CalSync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mirror events from one work calendar onto a dedicated calendar whose only attendee is the user's personal email, so Calendar.app dispatches invitations that surface the events on a personal device — with full create/update/cancel sync over a rolling 30-day window.

**Architecture:** A JavaScript-for-Automation (JXA) script run by `osascript`. Pure sync logic (identity, reconcile, guards) lives in `src/lib.js` with no macOS dependencies and is unit-tested in the same JavaScriptCore engine. A thin adapter (`src/adapter.js`) drives Calendar.app for reads/writes; a runner (`src/main.js`) wires them together and loads config. A concatenation `build.sh` produces the runnable `dist/calsync.js`. launchd runs it on a schedule; the same file runs manually.

**Tech Stack:** macOS `osascript -l JavaScript` (JavaScriptCore), Calendar.app via Apple events, launchd. No Node, no npm, no third-party dependencies.

## File Structure

- `src/lib.js` — **pure** logic: `encodeMarker`, `parseMarker`, `isSingleValidAttendee`, `reconcile`. No `ObjC`, no I/O, no side effects.
- `src/adapter.js` — JXA-only Calendar.app adapter: `getWorkInstances`, `getExistingCopies`, `applyCreate`, `applyUpdate`, `applyCancel`, `logLine`. Requires `src/lib.js` symbols to be in scope (guaranteed by concatenation).
- `src/main.js` — runner: config load, arg parse (`--dry-run`), window calc, wiring, summary log, invokes `run()`.
- `dist/calsync.js` — **generated** by `build.sh` (concatenation of the three `src/` files). The artifact `osascript`/launchd executes. Never edited by hand.
- `build.sh` — concatenates `src/lib.js` + `src/adapter.js` + `src/main.js` → `dist/calsync.js`.
- `tests/harness.js` — shared test helpers as a string that test files `eval`-include (assert fns, include helper).
- `tests/lib.test.js` — JXA test script for the pure logic. Run with `osascript -l JavaScript tests/lib.test.js`.
- `tests/harness.test.js` — proves the include + assert harness works.
- `install/net.beezwax.calsync.plist` — launchd LaunchAgent template.
- `install/install.sh` — writes config scaffold, builds, loads the LaunchAgent.
- `docs/superpowers/notes/` — findings from the two spikes.
- `~/.calsync/config.json` — runtime config (not in repo).
- `~/.calsync/calsync.log` — runtime log (not in repo).

**Config shape** (`~/.calsync/config.json`):
```json
{
  "workCalendarName": "Work",
  "dedicatedCalendarName": "CalSync Mirror",
  "personalEmail": "you@example.com",
  "windowDays": 30,
  "cancelThreshold": 0.25
}
```

**Pure data shapes** (used across tasks — keep names identical):
- **workInstance**: `{ workUid, title, startIso, endIso, allDay, isRecurring, occurrenceStartIso }`
  (`occurrenceStartIso` equals `startIso` for recurring occurrences; `null` for single events.)
- **copy**: `{ ref, url, title, startIso, endIso, allDay, attendees }`
  (`ref` is opaque — the Calendar event object in production, a stub in tests. `attendees` is an array of email strings.)
- **reconcile result**: `{ toCreate, toUpdate, toCancel, guardTripped, summary }`
  - `toCreate`: `[{ marker, title, startIso, endIso, allDay }]`
  - `toUpdate`: `[{ ref, marker, title, startIso, endIso, allDay }]`
  - `toCancel`: `[{ ref, marker }]`
  - `summary`: `{ created, updated, cancelled }`

**Identity rule (the key):** the marker string **is** the match key.
- Single event → `x-calsync://<workUid>` (time-independent, so a moved single event keeps its marker → update in place).
- Recurring occurrence → `x-calsync://<workUid>/<occurrenceStartIso>` (a moved occurrence gets a new marker → cancel-old + create-new).

```javascript
var CALSYNC_SCHEME = 'x-calsync://';

function encodeMarker(workUid, occurrenceStartIso, isRecurring) {
  if (isRecurring && occurrenceStartIso) {
    return CALSYNC_SCHEME + workUid + '/' + occurrenceStartIso;
  }
  return CALSYNC_SCHEME + workUid;
}

function parseMarker(url) {
  if (!url || url.indexOf(CALSYNC_SCHEME) !== 0) return null;
  var rest = url.slice(CALSYNC_SCHEME.length);
  var slash = rest.indexOf('/');
  if (slash === -1) return { workUid: rest, occurrenceStartIso: null };
  return { workUid: rest.slice(0, slash), occurrenceStartIso: rest.slice(slash + 1) };
}
```

- [ ] **Step 4: Implement `reconcile` in `src/lib.js`**

```javascript
function markerFor(workInstance) {
  return encodeMarker(workInstance.workUid, workInstance.occurrenceStartIso, workInstance.isRecurring);
}

function fieldsDiffer(workInstance, copy) {
  return workInstance.title !== copy.title
      || workInstance.startIso !== copy.startIso
      || workInstance.endIso !== copy.endIso
      || !!workInstance.allDay !== !!copy.allDay;
}

function reconcile(workInstances, copies, opts) {
  var threshold = (opts && typeof opts.cancelThreshold === 'number') ? opts.cancelThreshold : 0.25;

  var workByMarker = {};
  for (var i = 0; i < workInstances.length; i++) {
    workByMarker[markerFor(workInstances[i])] = workInstances[i];
  }
  var copyByMarker = {};
  for (var j = 0; j < copies.length; j++) {
    copyByMarker[copies[j].url] = copies[j];
  }

  var toCreate = [], toUpdate = [], cancelCandidates = [];

  // creates + updates
  for (var m in workByMarker) {
    if (!workByMarker.hasOwnProperty(m)) continue;
    var w = workByMarker[m];
    var existing = copyByMarker[m];
    if (!existing) {
      toCreate.push({ marker: m, title: w.title, startIso: w.startIso, endIso: w.endIso, allDay: !!w.allDay });
    } else if (fieldsDiffer(w, existing)) {
      toUpdate.push({ ref: existing.ref, marker: m, title: w.title, startIso: w.startIso, endIso: w.endIso, allDay: !!w.allDay });
    }
  }

  // cancels
  for (var c in copyByMarker) {
    if (!copyByMarker.hasOwnProperty(c)) continue;
    if (!workByMarker[c]) {
      cancelCandidates.push({ ref: copyByMarker[c].ref, marker: c });
    }
  }

  var guardTripped = false, toCancel = cancelCandidates;
  if (copies.length > 0 && (cancelCandidates.length / copies.length) > threshold) {
    guardTripped = true;
    toCancel = [];
  }

  return {
    toCreate: toCreate,
    toUpdate: toUpdate,
    toCancel: toCancel,
    guardTripped: guardTripped,
    summary: { created: toCreate.length, updated: toUpdate.length, cancelled: toCancel.length }
  };
}
```

## Task 6: Reader adapter (EventKit)

**Task 5 finding:** Calendar.app scripting returns only the master recurring event, not occurrences, and cannot see cancelled/moved instances. Therefore the Reader uses **EventKit**, whose occurrence enumeration expands the series and applies exceptions. See `docs/superpowers/notes/2026-07-01-reader-spike.md`. The write path (Task 7) stays on Calendar.app.

`getWorkInstances(calendarName, startDate, endDate)` returns an array of `workInstance`, or `null` when access is denied OR the named calendar is not found (both are "abort" conditions for the runner — failing to `null` is the safe choice, never a mass-cancel).

**Files:**
- Create: `src/adapter.js`

Identity mapping: `workUid = calendarItemExternalIdentifier`; single event → `isRecurring:false, occurrenceStartIso:null`; recurring occurrence → `isRecurring:true, occurrenceStartIso = ISO(occurrenceDate)`. This feeds the existing marker scheme unchanged.

- [ ] **Step 1: Implement `src/adapter.js`**

```javascript
ObjC.import('EventKit');
ObjC.import('Foundation');

function nsDate(js) { return $.NSDate.dateWithTimeIntervalSince1970(js.getTime() / 1000); }
function toIso(ekDate) { return ObjC.unwrap(ekDate).toISOString(); } // EKEvent NSDate -> JS Date -> ISO

// Requests full calendar access, spinning the run loop until the async callback fires.
// Returns true if granted, false otherwise (logged).
function ensureCalendarAccess(store) {
  var status = $.EKEventStore.authorizationStatusForEntityType($.EKEntityTypeEvent);
  if (status === 3 || status === 5) return true;   // 3=authorized(legacy) 5=fullAccess(macOS14+)
  var done = false, granted = false;
  var handler = function(g) { granted = g; done = true; };
  if (store.respondsToSelector($.NSSelectorFromString('requestFullAccessToEventsWithCompletion:'))) {
    store.requestFullAccessToEventsWithCompletion(handler);
  } else {
    store.requestAccessToEntityTypeCompletion($.EKEntityTypeEvent, handler);
  }
  var spins = 0;
  while (!done && spins < 600) { // up to ~60s
    $.NSRunLoop.currentRunLoop.runModeBeforeDate($.NSDefaultRunLoopMode, $.NSDate.dateWithTimeIntervalSinceNow(0.1));
    spins++;
  }
  if (!granted) console.log('CalSync: full calendar access not granted (status ' + status + ')');
  return granted;
}

// Returns array of workInstance, or null if access denied or calendar not found.
function getWorkInstances(calendarName, startDate, endDate) {
  var store = $.EKEventStore.alloc.init;
  if (!ensureCalendarAccess(store)) return null;

  var allCals = store.calendarsForEntityType($.EKEntityTypeEvent);
  var target = null, n = allCals.count;
  for (var i = 0; i < n; i++) {
    var c = allCals.objectAtIndex(i);
    if (ObjC.unwrap(c.title) === calendarName) { target = c; break; }
  }
  if (!target) { console.log('CalSync: work calendar not found: ' + calendarName); return null; }

  var predicate = store.predicateForEventsWithStartDateEndDateCalendars(
    nsDate(startDate), nsDate(endDate), $.NSArray.arrayWithObject(target));
  var evs = store.eventsMatchingPredicate(predicate); // expanded occurrences, exceptions applied

  var out = [], m = evs.count;
  for (var j = 0; j < m; j++) {
    var ev = evs.objectAtIndex(j);
    var isRecurring = !!ev.hasRecurrenceRules;
    var startIso = toIso(ev.startDate);
    out.push({
      workUid: ObjC.unwrap(ev.calendarItemExternalIdentifier),
      title: ObjC.unwrap(ev.title),
      startIso: startIso,
      endIso: toIso(ev.endDate),
      allDay: !!ev.isAllDay,
      isRecurring: isRecurring,
      occurrenceStartIso: isRecurring ? (ev.occurrenceDate.isNil() ? startIso : toIso(ev.occurrenceDate)) : null
    });
  }
  return out;
}
```

```javascript
// Creates a copy in the dedicated calendar. Enforces single-attendee guardrail.
// Returns true on success, false if refused/failed (already logged).
function applyCreate(dedicatedCal, item, personalEmail) {
  var Cal = Application('Calendar');
  var props = {
    summary: item.title,
    startDate: isoToDate(item.startIso),
    endDate: isoToDate(item.endIso),
    alldayEvent: item.allDay,
    url: item.marker
  };
  var ev = Cal.Event(props);
  dedicatedCal.events.push(ev);
  // add the single attendee
  var att = Cal.Attendee({ email: personalEmail });
  ev.attendees.push(att);

  // GUARDRAIL: assert exactly one attendee equal to personalEmail
  var emails = [];
  try { var atts = ev.attendees(); for (var i = 0; i < atts.length; i++) emails.push(atts[i].email()); } catch (e) {}
  if (!isSingleValidAttendee(emails, personalEmail)) {

  return true;
```

```javascript
function run() {
  var dryRun = hasFlag('--dry-run');
  var cfg = loadConfig();
  var now = new Date();
  var end = new Date(now.getTime() + (cfg.windowDays || 30) * 864e5);

  var work = getWorkInstances(cfg.workCalendarName, now, end);
  if (work === null) {
    logLine('ABORT work calendar not found: ' + cfg.workCalendarName);
    return;
  }

  var copies = getExistingCopies(cfg.dedicatedCalendarName, now, end);
  var plan = reconcile(work, copies, { personalEmail: cfg.personalEmail, cancelThreshold: cfg.cancelThreshold });

  if (dryRun) {
    logLine('DRYRUN plan create=' + plan.toCreate.length + ' update=' + plan.toUpdate.length +
            ' cancel=' + plan.toCancel.length + ' guardTripped=' + plan.guardTripped);
    return;
  }

  var Cal = Application('Calendar');
  var dedCals = Cal.calendars.whose({ name: cfg.dedicatedCalendarName })();
  if (dedCals.length === 0) { logLine('ABORT dedicated calendar not found: ' + cfg.dedicatedCalendarName); return; }
  var dedicatedCal = dedCals[0];

  var created = 0, updated = 0, cancelled = 0;
  var i;
  for (i = 0; i < plan.toCreate.length; i++) { if (applyCreate(dedicatedCal, plan.toCreate[i], cfg.personalEmail)) created++; }
  for (i = 0; i < plan.toUpdate.length; i++) { if (applyUpdate(plan.toUpdate[i], cfg.personalEmail)) updated++; }
  for (i = 0; i < plan.toCancel.length; i++) { if (applyCancel(plan.toCancel[i])) cancelled++; }

  logLine('RUN created=' + created + ' updated=' + updated + ' cancelled=' + cancelled +
          ' guard=' + (plan.guardTripped ? 'tripped' : 'ok'));
}

run();
```
